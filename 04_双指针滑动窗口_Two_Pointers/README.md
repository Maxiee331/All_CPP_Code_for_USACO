# 04 双指针 / 滑动窗口 Two Pointers & Sliding Window

这两道都是**自主练习题**（不是 USACO 真题），但滑动窗口是银组常用技巧。

## 题目

### string searching.cpp
- **类型**：练习题（经典题：**最长无重复字符子串**）
- **算法**：**滑动窗口 + `set` 判重**

**思路**：`right` 往右扩，如果 `stri[right]` 已在窗口内，
就从 `left` 开始收缩、边收边从 `set` 里删，直到重复字符被移出。
每步更新 `ans = max(ans, 窗口大小)`。

**复杂度**：`O(n log n)`（`set` 操作带 log）。
用 `int cnt[128]` 数组代替 `set` 可以做到 `O(n)`。

**代码点评**：这个写对了 ✅ —— `while` 收缩的位置和时机都正确。

### num adding.cpp
- **类型**：练习题（经典题：**和 ≥ S 的最短子数组**）
- **算法**：**滑动窗口（可变长度）**

**思路**：`right` 扩张累加，一旦 `suma >= S` 就记录长度并从左收缩。

**代码点评**：主体逻辑对 ✅，但有两个小问题：
1. `while (suma >= 7)` 把 `S` **写死成 7** 了，应该用 `S` 变量
2. 前面已经判过 `maxsum < S` 提前返回，所以 `ans` 一定会被更新 —— 这个处理是好的

## 滑动窗口模板

```cpp
int left = 0;
for (int right = 0; right < n; right++) {
    加入 a[right] 到窗口;

    while (窗口不满足条件) {
        移出 a[left] ;
        left++;
    }

    更新答案;   // 此时 [left, right] 是一个合法窗口
}
```

**关键点**：`left` 只往右走、**永不回退**，所以总共移动 `n` 次
→ 整体是 `O(n)` 而不是 `O(n²)`。这就是双指针比暴力快的原因。

**什么时候能用**：
- 求**连续**子数组/子串的最长/最短
- 窗口有**单调性**（扩张让条件更容易/更难满足，方向固定）
